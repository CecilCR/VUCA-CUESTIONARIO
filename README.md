# 📊 Cuestionario interactivo: Estrategia y desafíos en entornos organizacionales

Herramienta de evaluación interactiva con retroalimentación inmediata y efecto de celebración para el curso de Gestión de las relaciones en las organizaciones.

## 🎯 Características

- ✅ **5 preguntas** de opción múltiple sobre entornos VUCA, economía colaborativa y nuevos modelos organizacionales
- 🎊 **Efecto confetti** en respuestas correctas
- 💬 **Retroalimentación pedagógica** inmediata en cada respuesta
- 📊 **Resultados personalizados** según desempeño
- 📱 **100% responsivo** - funciona en cualquier dispositivo
- 🚀 **Sin instalación** - abre directamente en el navegador

## 🚀 Uso rápido

### Opción 1: Descarga directa
1. Descarga `cuestionario-estrategia.html`
2. Abre el archivo en tu navegador
3. ¡Comienza a responder!

### Opción 2: GitHub Pages
Accede directamente desde: `[tu-usuario].github.io/[repo]/cuestionario-estrategia.html`

### Opción 3: Código QR
Escanea el código QR proporcionado por tu docente para acceso inmediato desde tu móvil.

1. Economía colaborativa y gestión de confianza
